# 14: Re-run analysis on a saved document

**What to build:** From a saved document, the renter edits their profile and re-runs the analysis on the stored text and sections, without re-uploading. The new report and the new profile snapshot replace the old ones; no report history is kept (owner decision). The re-run goes through the same analysis route, so citations are verified the same way.

**Status:** ready-for-agent
